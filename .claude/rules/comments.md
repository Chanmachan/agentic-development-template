# Comment Rules

コメントは原則書かない (2026-07-21 合意)。守りたいものはコードの外に置く:

1. 振る舞い・制約 → テスト / lint / 検証スクリプトで表明する
2. 設計判断 → `tasks/<id>-todo.md` / done ドキュメントへ
3. 経緯・出所 → PR 本文へ

コードコメントは上のどれにも載せられない**不可視制約の最終手段のみ**。1 行に圧縮し、日付・人名・経緯・issue 番号を含めない。

残してよいもの:
- 「無いことが意図的」系 (認可を意図的に hospital スコープに留めている、`therapist_id` が常に nil のため担当一致判定を使わない、等)
- 外部ライブラリのバグ/挙動の回避 (`youtube_player_iframe` の `controller.value.playerState` が更新されないため API 照会する、等)
- `ignore:` / `rubocop:disable` / `eslint-disable` の理由 (ツール要求形式)
- テストの魔法値の意味注釈 (`// JST 14:30` 等)

書かないもの: 出所・日付・人名、todo/spec の引用、コードの動作をなぞる説明、copy-adapt 元の言及、レビュアーへの弁明。
可能なら残す側の制約もテスト/検証スクリプトへ昇格させてからコメントを消す。

再発した回避策は `.claude/rules/pitfalls.md` に昇格させ、コード側のコメントは消す。
